# Histórico compartilhado no Supabase

O Nukenin Trading Co. usará o Supabase para persistir Watchlist, histórico compartilhado e snapshots diários de preço. Essa escolha substitui o armazenamento local como fonte de verdade, permitindo que a equipe observe as mesmas quedas e evitando que a limpeza do navegador apague o histórico.
